Проверь проект, ничего не исправляя. Работай в текущей сессии.

Последовательно запусти команды, по одной, не объединяя их через `&&` или `;`:

1. `npm run typecheck`
2. `npm test -- --ci`
3. `npm run lint`

Даже если предыдущая команда упала, запусти следующую — нужен полный результат.
Сохрани код возврата каждой команды.

## Формат отчёта

Отчёт на русском.

### Результат

- `typecheck` — ✅/❌
- `tests` — ✅/❌
- `lint` — ✅/❌

### Ошибки

Если всё зелёное — коротко напиши, что все три проверки прошли, и перечисли
запущенные команды.

Если есть ошибки — сгруппируй их по файлам: `путь:строка`, текст ошибки, вероятная
причина. Укажи, какая команда упала и сколько ошибок всего. Ничего не исправляй
и не меняй файлы.
