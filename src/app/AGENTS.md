# src/app — экраны и навигация

`src/app/` — файловая маршрутизация **expo-router**. Каждый файл здесь (кроме
`_layout.tsx`) — экран с `export default`. Любой лишний файл (компонент, хук, тест)
станет маршрутом, поэтому в этой папке только экраны.

## Маршруты

| Файл | Маршрут | Назначение |
| --- | --- | --- |
| `_layout.tsx` | — | Корневой layout: `SQLiteProvider databaseName='schedule.db' onInit={migrateDb}` вокруг `Stack` (`headerShown: false`), `initNotifications()`, загрузка настроек, `setNotificationHandler` |
| `index.tsx` | `/` | `<Redirect href='/(tabs)/today' />` |
| `(tabs)/_layout.tsx` | — | Нижние вкладки «Сегодня / Неделя / Настройки», `useNotificationSync()` |
| `(tabs)/today.tsx` | `/today` | Текущий/следующий урок, секции дня |
| `(tabs)/week.tsx` | `/week` | Неделя, копирование |
| `(tabs)/settings.tsx` | `/settings` | Настройки |
| `lesson.tsx` | `/lesson` | Форма создания/редактирования урока |

- `index.tsx` обязателен: dev-клиент открывает приложение по `scheduler:///`, и без
  маршрута `/` появляется «Unmatched Route».
- `unstable_settings = { initialRouteName: '(tabs)' }` в корневом layout.
- Типы маршрутов генерируются при старте dev-сервера: после добавления экрана
  перезапустить `npx expo start --dev-client -c`.
- Импортировать `Link`, `router`, `useLocalSearchParams`, `useFocusEffect` из
  `expo-router`.

## Корневой layout (`_layout.tsx`)

- `SQLiteProvider` оборачивает `Stack`; хуки с `useSQLiteContext()` вызываются только
  внутри провайдера (поэтому `useNotificationSync` — в `(tabs)/_layout.tsx`, а не здесь).
- В `useEffect` при старте: `initNotifications()` и
  `useSettingsStore.getState().loadSettings()`.
- `Notifications.setNotificationHandler(...)` задан на уровне модуля (остался от прежней
  схемы; показывает баннер/список, без звука и бейджа).
- Порядок инициализации уведомлений важен: сначала каналы, потом разрешение
  (`initNotifications`).

## Общий каркас экранов

`src/components/Screen.tsx`: пропсы `title`, `children`. Даёт:

- верхний отступ `useSafeAreaInsets().top + TOP_GAP` (`TOP_GAP = 28`);
- фон `#f4f4f8`, горизонтальные поля 16;
- заголовок 28 px bold `#1c1c28`.

Все три вкладки используют `Screen`. **Свой `paddingTop` на вкладках не добавлять** —
иначе заголовок съедет на телефонах с вырезом. Форма `lesson.tsx` пока со своим
`paddingTop: 60` и без `Screen` (известный мелкий долг).

## «Сегодня» (`today.tsx`)

- Данные: `todayLessons` из `useLessonStore`, `loadToday(db)` при фокусе вкладки.
- `now` — локальный `useState`; `setInterval` раз в секунду обновляет `now` **только
  при смене минуты** и перезагружает уроки при смене суток. Таймер очищается в
  `useFocusEffect`.
- Один `SectionList`: `ListHeaderComponent` — `NowCard` «Текущий урок» (accent) и
  «Следующий урок»; секции «Остальные уроки», «Прошедшие уроки», «Отменённые уроки»,
  пустые секции отфильтрованы.
- Пустые состояния: уроков нет → «Сегодня уроков нет»; уроки есть, но текущего и
  следующего нет → «Уроков сегодня больше нет».
- Известная мелочь: если на сегодня только отменённые уроки, показывается «Уроков сегодня
  больше нет» (условие `lessons.length > 0`; правильно — `lessons.some(l => !l.cancelled)`).
- Расчет текущего/следующего — только через `getCurrentAndNextLessons` из `domain`.

## «Неделя» (`week.tsx`)

- `weekStart` — локальный `useState` (понедельник), переключатель ‹ ›, подпись
  `formatWeek` («5 окт – 11 окт»), кнопка «Текущая неделя».
- Загрузка через `useFocusEffect(useCallback(...))`, потому что вкладки не размонтируются.
- 7 `DayCard` (пн–вс), у каждого кнопка «＋» (создать урок на дату) и список `LessonCard`.
- «Скопировать неделю»: последовательно проверяет 8 предыдущих недель через
  `countLessonsForWeek`, показывает `CopyLessonsModal` со списком непустых недель.
  Если на целевой неделе уже есть уроки — `Alert` с подтверждением. Копирование — через
  действие стора `copyWeek`.
- `key` ставится на `<DayCard>` в `.map`, а не внутри компонента.

## Форма урока (`lesson.tsx`)

- Открывается: `router.push({ pathname: '/lesson', params: { date } })` для нового или
  `{ id: String(id) }` для редактирования. Режим определяется по наличию `id`.
  Навигация инкапсулирована в `useLessonActions` (`addLesson`, `openLesson`).
- Поля: дата, начало, конец, класс, кабинет, тема (multiline), «Урок отменён».
- Дата/время — системные пикеры через `PickerField` (`DateTimePickerAndroid.open`,
  только Android). В состоянии формы — строки `ГГГГ-ММ-ДД` / `ЧЧ:ММ`, дата показывается
  как `ДД.ММ.ГГГГ` (`formatDateRu`).
- При смене начала конец автоматически = начало + `lessonDurationMinutes`
  (`addMinutesToTime`, максимум `23:59`). Это работает и для нового урока, и при
  редактировании при смене начала; при открытии существующего урока значения из БД не
  перезаписываются.
- Валидация: `endTime > startTime` (строковое сравнение) и непустой класс.
- Сохранение — `saveLesson` из стора, затем `router.back()`.
- Известный долг: нет проверки пересечения с другими уроками дня (баг №2); при
  `lessonEndingMinutes` больше длительности урока план уведомлений некорректен (баг №1).

## «Настройки» (`settings.tsx`)

- Секция «Уведомления»: «Уведомление о первом уроке за», «Предупредить о конце урока за»,
  «Разрешение на уведомления».
- Секция «Расписание»: «Длительность урока по умолчанию».
- Внизу `BatteryHint`.
- Нажатие на числовую строку открывает `OptionPickerModal` (готовые варианты +
  «Своё значение…», проверка диапазона). После выбора: закрыть окно,
  `await updateSettings(...)`, затем `syncNotifications(db)` без `await` с `.catch`.
- Разрешение (`useNotificationPermission`):
  - `granted` — «Выдано», строка не нажимается;
  - `canAsk` — «Не выдано» красным, нажатие вызывает `ensureNotificationPermission()`,
    затем `refresh()` и при успехе пересобирает уведомления;
  - `blocked` — «Не выдано», нажатие открывает `Linking.openSettings()`.
- Не реализовано: подсказка про «Не беспокоить»/беззвучный режим.

## Правила и грабли

- Не импортировать `@/store/lessonsStore` в компонент ради действий — есть
  `useLessonActions`.
- `useFocusEffect` **требует** колбэк в `useCallback`, иначе бесконечный цикл. Внутри
  таймеры очищать в возвращаемой функции.
- `{x && <Comp/>}` при `x === 0` рисует `0` вне `<Text>` и падает: сравнивать явно
  (`x !== null`, `x > 0`).
- Вложенные вертикальные списки (`FlatList` в `ScrollView`/`FlatList`) запрещены —
  использовать `SectionList` или `ListHeaderComponent`.
- `async`-функцию нельзя передавать в `useEffect` напрямую: `useEffect(() => { fn(); }, [])`
  или IIFE.
- Не менять `endTime`/`startTime` в обход `addMinutesToTime` при автоподстановке:
  функция не переходит через полночь (максимум `23:59`).
- Навигационные параметры — строки; `id` приводить через `Number(id)`.
