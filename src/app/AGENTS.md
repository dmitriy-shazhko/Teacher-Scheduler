# src/app — экраны и навигация

`src/app/` — файловая маршрутизация **expo-router**. Каждый файл здесь (кроме
`_layout.tsx`) — экран с `export default`. Любой лишний файл (компонент, хук, тест)
станет маршрутом, поэтому в этой папке только экраны.

## Маршруты

| Файл | Маршрут | Назначение |
| --- | --- | --- |
| `_layout.tsx` | — | Корневой layout: `SQLiteProvider databaseName='schedule.db' onInit={migrateDb}` вокруг `Stack` (`headerShown: false`), `initNotifications()`, загрузка настроек, `setNotificationHandler` |
| `index.tsx` | `/` | `<Redirect href='/(tabs)/today' />` |
| `(tabs)/_layout.tsx` | — | Нижние вкладки «Сегодня / Неделя / Настройки» (иконки Feather, цвета из `colors`, `tabBarButton: TabBarButton`), `useNotificationSync()` |
| `(tabs)/today.tsx` | `/today` | Текущий/следующий урок, секции дня |
| `(tabs)/week.tsx` | `/week` | Неделя, копирование |
| `(tabs)/settings.tsx` | `/settings` | Настройки |
| `lesson.tsx` | `/lesson` | Форма создания/редактирования урока |

- `index.tsx` обязателен: dev-клиент открывает приложение по `scheduler:///`, и без
  маршрута `/` появляется «Unmatched Route».
- `unstable_settings = { initialRouteName: '(tabs)' }` в корневом layout.
- `tabBarButton: TabBarButton` в `screenOptions` — свой `Pressable` без стандартного
  Android-риппла (серый круг при нажатии на вкладку). Кнопка живёт в
  `src/components/TabBarButton.tsx`.
- Типы маршрутов генерируются при старте dev-сервера: после добавления экрана
  перезапустить `npx expo start --dev-client -c`.
- Импортировать `Link`, `router`, `useLocalSearchParams`, `useFocusEffect` из
  `expo-router`.

## Корневой layout (`_layout.tsx`)

- `SQLiteProvider` оборачивает `Stack`; хуки с `useSQLiteContext()` вызываются только
  внутри провайдера (поэтому `useNotificationSync` — в `(tabs)/_layout.tsx`, а не здесь).
- В `useEffect` при старте: `initNotifications()` и
  `useSettingsStore.getState().loadSettings()`.
- `Notifications.setNotificationHandler(...)` задан на уровне модуля (остался от прежней
  схемы; показывает баннер/список, без звука и бейджа).
- Порядок инициализации уведомлений важен: сначала каналы, потом разрешение
  (`initNotifications`).

## Общий каркас экранов

`src/components/Screen.tsx`: пропсы `title`, `children`, `rightBlock?`, `onBack?`. Даёт:

- верхний отступ `useSafeAreaInsets().top + TOP_GAP` (`TOP_GAP = 28`);
- фон `colors.bg` (`@/domain/theme`), горизонтальные поля 16;
- заголовок 28 px bold `colors.text`;
- `rightBlock` — элемент справа от заголовка (на «Неделе» — `IconButton` «Копировать
  неделю»);
- `onBack` — строка «‹ Назад» над заголовком; передаётся только формой урока
  (`lesson.tsx`), отдельной кнопки «Назад» на экранах нет.

Все экраны, включая форму урока, используют `Screen`. **Свой `paddingTop` на экранах не
добавлять** — иначе заголовок съедет на телефонах с вырезом.

## «Сегодня» (`today.tsx`)

- Данные: `todayLessons` из `useLessonStore`, `loadToday(db)` при фокусе вкладки.
- `now` — локальный `useState`; `setInterval` раз в секунду обновляет `now` **только
  при смене минуты** и перезагружает уроки при смене суток. Таймер очищается в
  `useFocusEffect`.
- Под заголовком — дата `formatDateFull(now)` → «воскресенье, 15 ноября».
- Крупная карточка `NowCard` (макеты `templates/today-active.html` и
  `templates/today-soon.html`):
  - есть идущий урок — `state='active'`, бейдж «Идёт сейчас» (`currentBg`/`currentText`/
    `currentDot`), полоса прогресса `lessonProgress(current, now)` и подпись
    «Осталось N мин»;
  - идущего нет, но есть ближайший будущий — `state='soon'`, бейдж «Скоро начнётся»
    (`soonBg`/`soonText`/`soonDot`), без полосы, подпись «Начнётся через N мин».
  - нажатие на карточку — `openLesson`.
- Один `SectionList`: `ListHeaderComponent` — `NowCard`, дальше секции «Следующий»
  (первый будущий урок после карточки: акцент, справа бейдж «через N мин», карточка с
  рамкой `LessonCard highlighted`) и «Позже» (остальные будущие); пустые секции
  отфильтрованы. Прошедшие и отменённые уроки на этом экране **не показываются**.
- Пустые состояния: уроков за день нет вообще → «Сегодня уроков нет»; уроки есть, но
  ни текущего, ни будущего нет (например, только прошедшие или отменённые) →
  «Уроков сегодня больше нет».
- Расчет текущего/следующего — только `getCurrentAndNextLessons`, прогресс —
  `lessonProgress`, сортировка будущих — `sortDayLessons` (всё из `domain`).
- Удаление урока — корзина в `LessonCard` (`confirmRemove`), отдельного долгого нажатия
  больше нет, поэтому удалять можно и с этой вкладки.

## «Неделя» (`week.tsx`)

- `weekStart` — локальный `useState` (понедельник); `selected` — индекс выбранного дня
  (0 = понедельник), при открытии равен сегодняшнему дню.
- `WeekSwitcher` — ‹ ›, подпись `formatWeek` («5 окт – 11 окт»); если открыта не текущая
  неделя, вместо подписи «Текущая неделя» показывается кликабельное «К текущей неделе».
- `DayStrip` — 7 пилюль пн–вс с точкой под числом: точка `colors.primary` — в дне есть
  уроки (`weekLessonDays(lessons, weekStart)` из `domain/schedule`; отменённые тоже
  считаются, они видны в списке дня), пустой день — текст `colors.muted` без точки.
  `todayIndex` — сравнение `toDateString(addDays(...))` с сегодняшней датой; `-1`, если
  сегодня не на этой неделе.
- Под полосой — шапка выбранного дня: `WEEKDAYS[selected], 12 ноя` и сводка
  `pluralLessons(n)` + диапазон `первое начало – последний конец` (или «Уроков нет»).
  Диапазон считает `dayTimeRange` из `domain` — по самому раннему началу и позднему концу,
  отменённые уроки тоже учитываются.
- Кнопка «＋» в шапке создаёт урок **на выбранный день** (`dayStr`), а не на сегодня.
- Список — `SectionList` с тремя секциями (`LessonSectionHeader`): «Активные уроки»
  (акцент), «Прошедшие уроки» (приглушённый) и «Отменённые уроки» (`cancelled`); в заголовке
  секции — количество уроков, пустые секции скрыты; пустой день — «В этот день уроков
  нет». Деление даёт `splitDayLessons(dayLessons, now)` из `domain/schedule`: отменённые
  всегда отдельно, день в прошлом — весь прошедший, день в будущем — весь активный,
  сегодня — по границе `end <= now`; внутри группы по времени начала. Карточки прошедших
  уроков получают `LessonCard passed` — приглушённые время и класс; отменённые
  приглушаются так же (`LessonCard` делает это сам по `lesson.cancelled`).
- `now` — локальный `useState`; `setInterval` раз в секунду обновляет его **только при
  смене минуты**, поэтому урок сам переезжает из «активных» в «прошедшие», а `todayIndex`
  и подпись текущей недели обновляются при смене суток. Таймер очищается в
  `useFocusEffect`.
- Загрузка через `useFocusEffect(useCallback(...))`, потому что вкладки не размонтируются;
  `load` зависит от `weekStart`, поэтому листание недель перезагружает данные.
- «Скопировать неделю» — `IconButton` в `Screen.rightBlock`: последовательно проверяет
  8 предыдущих недель через `countLessonsForWeek`, показывает `CopyLessonsModal` со
  списком непустых недель. Если на целевой неделе уже есть уроки — `Alert` с
  подтверждением. Копирование — через действие стора `copyWeek`. Пока `isCopying`,
  повторные нажатия игнорируются, а строки источника неактивны (`isBusy`) — иначе двойной
  тап создаёт два набора уроков.
- После копирования экран переключается на день, где появились уроки и который ближе
  всего к сегодняшнему (`nearestWeekdayIndex` из `domain/dates`; при равном расстоянии
  выбирается будущий день). Так копирование видно сразу, даже если выбранный день пуст.
- `keyExtractor` в `SectionList` — `item.id.toString()`; `key` в массиве ставит родитель,
  а не сам компонент.
- Ограничения: `selected` не сбрасывается на сегодня при листании недель и нажатии
  «К текущей неделе» — остаётся тот же день недели; сводка дня считает и отменённые уроки.

## Форма урока (`lesson.tsx`)

- Открывается: `router.push({ pathname: '/lesson', params: { date } })` для нового или
  `{ id: String(id) }` для редактирования. Режим определяется по наличию `id`.
  Навигация инкапсулирована в `useLessonActions` (`addLesson`, `openLesson`).
- Разметка — как в шаблонах: белая карточка `FormCard` со строками `FormRow`
  «Дата», «Время», «Класс», «Кабинет», «Тема» (подпись слева `colors.muted`, значение
  справа жирным). «Тема» — блок (`isBlock`): маленькая подпись сверху, многострочный
  `TextInput` под ней.
- Дата — системный Android-пикер (`PickerField`, `DateTimePickerAndroid.open`). Время
  редактируется нижним листом `TimePickerModal` (макет `templates/pick-time.html`):
  нажатие на строку «Время» открывает шторку с карточками «Начало/Конец», кнопками
  длительности (значения из настроек `SETTING_OPTIONS.lessonDurationMinutes` плюс дефолт
  и фактическая длительность урока, если их нет в списке) и «Готово».
  Изменения применяются только по «Готово»; закрытие по подложке/системной кнопке
  «Назад» их отбрасывает.
- Барабанов нет: нажатие на карточку «Начало» или «Конец» открывает системный пикер
  времени (`openDateTimePicker`, строка `ЧЧ:ММ` ⇄ `Date` через `timeToDate`/`dateToTime`).
  При смене начала конец сдвигается, сохраняя текущую длительность; кнопка длительности
  ставит конец = начало + N минут (`addMinutesToTime`); активна кнопка, равная
  `timeDiff(start, end)` (`domain/schedule`).
- В состоянии формы — строки `ГГГГ-ММ-ДД` / `ЧЧ:ММ`, дата показывается как
  `ДД.ММ.ГГГГ` (`formatDateRu`), время — `08:30 – 09:15`. Незаполненные поля (класс,
  кабинет, тема) показывают подсказку цветом `colors.placeholder` — светлее `muted`,
  чтобы пустое значение не выглядело как заполненное.
- «Урок отменён» и «Удалить урок» есть только в режиме редактирования (как в
  шаблоне): карточка со `Switch` (`barMuted`/`primary`) и красная кнопка с `Feather`
  `trash-2`. Удаление — `confirmRemove(id, () => router.back())`: после удаления экран
  закрывается.
- Валидация: `endTime > startTime` (строковое сравнение) и непустой класс.
- Сохранение — `saveLesson` из стора, затем `router.back()`. Повторное нажатие
  игнорируется (`isSaving`), кнопка заблокирована — иначе быстрый двойной тап вставляет
  урок дважды.
- Известный долг: нет проверки пересечения с другими уроками дня (баг №2); при
  `lessonEndingMinutes` больше длительности урока план уведомлений некорректен (баг №1).

## «Настройки» (`settings.tsx`)

- Секция «Уведомления»: «Уведомление о первом уроке за», «Предупредить о конце урока за»,
  «Разрешение на уведомления».
- Секция «Расписание»: «Длительность урока по умолчанию».
- Внизу `BatteryHint`.
- Нажатие на числовую строку открывает `OptionPickerModal` (готовые варианты +
  «Своё значение…», проверка диапазона). После выбора: закрыть окно,
  `await updateSettings(...)`, затем `syncNotifications(db)` без `await` с `.catch`.
- Разрешение (`useNotificationPermission`):
  - `granted` — «Выдано», строка не нажимается;
  - `canAsk` — «Не выдано» красным, нажатие вызывает `ensureNotificationPermission()`,
    затем `refresh()` и при успехе пересобирает уведомления;
  - `blocked` — «Не выдано», нажатие открывает `Linking.openSettings()`.
- Не реализовано: подсказка про «Не беспокоить»/беззвучный режим.

## Правила и грабли

- Не импортировать `@/store/lessonsStore` в компонент ради действий — есть
  `useLessonActions`.
- `useFocusEffect` **требует** колбэк в `useCallback`, иначе бесконечный цикл. Внутри
  таймеры очищать в возвращаемой функции.
- `{x && <Comp/>}` при `x === 0` рисует `0` вне `<Text>` и падает: сравнивать явно
  (`x !== null`, `x > 0`).
- Вложенные вертикальные списки (`FlatList` в `ScrollView`/`FlatList`) запрещены —
  использовать `SectionList` или `ListHeaderComponent`.
- `async`-функцию нельзя передавать в `useEffect` напрямую: `useEffect(() => { fn(); }, [])`
  или IIFE.
- Не менять `endTime`/`startTime` в обход `addMinutesToTime` при автоподстановке:
  функция не переходит через полночь (максимум `23:59`).
- Навигационные параметры — строки; `id` приводить через `Number(id)`.
